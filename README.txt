CLICK-ME-FIRST GitHub Builder

This package builds a Windows EXE using GitHub's Windows runner, so Python
does not need to be installed on your own computer.

1. Create a GitHub repository.
2. Upload all files/folders from this package, including .github/workflows/build.yml.
3. Open the repository's Actions tab.
4. Select "Build CLICK-ME-FIRST".
5. Click "Run workflow".
6. When it completes, open the workflow run and download the artifact
   named CLICK-ME-FIRST-Windows.
7. The artifact contains CLICK-ME-FIRST.exe.

The launcher activation server is:
https://activation-code.onrender.com

This is a clean activation launcher and does not include hidden code from
the previous executable.
